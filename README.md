# Montu Soni Website

यह वेबसाइट अलग-अलग पेजों में व्यवस्थित है:

1. `index.html` — Home
2. `services.html` — Services
3. `portfolio.html` — Portfolio
4. `get-started.html` — Pricing और enquiry form
5. `contact.html` — Contact form और contact details

सभी पेजों की navigation links आपस में जुड़ी हुई हैं। किसी भी पेज को सीधे browser में खोल सकते हैं या पूरे फ़ोल्डर को web hosting पर upload कर सकते हैं।
